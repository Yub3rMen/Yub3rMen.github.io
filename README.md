# IT & Networking Portfolio

Static GitHub Pages site demonstrating networking, Linux administration, self-hosted services and troubleshooting.

## Publishing

Upload `index.html`, `assets/favicon.svg`, and `.nojekyll` to the root of the `Yub3rMen.github.io` repository. Enable **Settings > Pages > Deploy from a branch > main > /(root)**.

## Before sharing with employers

This is an initial portfolio overview. Add screenshots, verified configurations, sanitized topology diagrams, and project case studies before treating the documentation as complete. Replace the generic display branding and connect professional contact information once chosen. Do not publish passwords, private network endpoints or identifiers, tokens, or customer network information.
